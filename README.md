# Food Delivery App

A full-stack food delivery application inspired by Swiggy and Zomato.

## Features

- User Authentication
- Restaurant Management
- Product Management
- Add To Cart
- Order Management
- Image Uploads
- Responsive UI

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Multer

## Project Structure

food-delivery-app
├── frontend
└── backend

## Installation

### Backend

cd backend

npm install

npm run dev

### Frontend

cd react-dashboard

npm install

npm run dev
